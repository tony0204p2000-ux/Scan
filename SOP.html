收料核對 操作說明

手機掃描廠商外箱標籤，核對 Lot No 與數量是否與收料資料相符

https://tony0204p2000-ux.github.io/Scan/Receiving.html

基本流程

1開啟網址、選擇收料 Excel

  • 手機用 Chrome / Safari 開上方網址（建議「加入手機主畫面」）
  • 按 選擇檔案 選瑞昱上傳的整理Excel，可一次選多個檔案自動合併

2確認載入筆數

  • 上方顯示「已核對 / 總筆數」與 正確 不符 未核對 統計
  • 進度會自動保存，重新整理或切換 App 都不會遺失
  • 一批貨核對完成要上傳下一批檔案進行核對時按 重新上傳（會清除目前進度）

3按「📷 掃描條碼」對準標籤

  • 對準廠商標籤上的 QR Code / 二維碼，系統自動判斷是哪家廠商並取出 Lot No 與數量
  • 同一張標籤上其他條碼（料號、PO、日期…）會自動略過
  • Lot 與數量分開的條碼（如弘憶、愛普），兩個條碼都掃到即可，順序不拘
  • 掃描框可按畫面上方 框 切換（預設：小、長方）
  • 可連續掃描，全部掃完按 完成
讀不到時：手機靠近讓條碼在框內變大 → 按 放大（Android）→ 改按下方 拍照讀取（用完整畫質解碼，iPhone 掃很密的 QR Code 時最可靠）

4看核對結果

  • ✅ 核對正確：Lot No 與數量都符合
  • ❌ 數量不符：手機會震動，顯示應收與標籤數量，請檢查實物
  • ❌ 找不到此 Lot No：不在收料資料中，確認是否瑞昱上傳的資料有短少
  • ⚠️ 已核對過：同一箱重複掃描
  • 所有異常都記錄在「刷讀異常紀錄」，可事後回頭查

特殊情況

5條碼受損／純文字標籤：人工核對

  • 適用條碼受損、讀不到，或沒有條碼的純文字標籤（如聯強、艾睿、光菱）
  • 在核對清單直接點該筆（左圖紅框；可先在搜尋框輸入 Lot No 找出該筆）
  • 跳出大字的 C_LOT 與 GOOD_DIE_QTY，對照實物標籤
  • 相符按 ✅ 確認相符，等同刷讀成功並列入刷讀順序
  • 按錯時點已核對的項目 → ↩ 改回未核對

＋手機外接條碼槍（藍牙／OTG）

  • 連上條碼槍後直接掃即可，不用先點輸入框；條碼槍需設定掃完送出 Enter（多數預設即是）
  • Lot 與數量分開的標籤：先掃 Lot No，再掃數量
  • 華邦電、旺宏的二維碼經條碼槍讀取時，分隔字元常被吃掉而黏成一串，程式會自動拆解（結果會標示「分隔字元遺失，已自動拆解」）
  • 也可以在「手動輸入」框打字或貼上內容後按 核對

收尾

6匯出 Excel／設定

  • 依刷讀順序匯出 Excel：產生排序標籤檔案，供奕楊列印
  • 短少清單：還沒核對到的項目
  • 刷讀異常紀錄：找不到、重複、數量不符、人工核對的紀錄
  • ⚙️ 設定：勾選掃描框種類（每支手機各自保存）
